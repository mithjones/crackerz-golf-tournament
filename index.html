Google Sheets sync

Paste your Apps Script Web App URL to enable automatic cloud sync between everyone's browser and the shared Sheet.

Follow the setup guide below to get your URL.

Quick setup

  1. 1Open Google Sheets, create a new blank spreadsheet named Crackerz Golf Tournament.
  2. 2Click Extensions → Apps Script. Delete any existing code.
  3. 3Open Crackerz_Google_Apps_Script.js, select all, paste into the Apps Script editor. Save.
  4. 4Click Deploy → New deployment. Type: Web app. Execute as: Me. Who has access: Anyone. Deploy, and authorise when asked.
  5. 5Copy the Web app URL (ends in /exec). Paste it above and click Connect.
  6. 6Click Push to Sheet once to write anything already entered locally, or Pull from Sheet if the Sheet already has data.

How the sync works

Every change — ticking your availability, editing a fixture's location or booker, saving scores — saves instantly to this browser, then pushes to the Sheet a few seconds later. Opening the app pulls the latest from the Sheet and merges by whichever change is newest, so it's safe for more than one person to be updating things around the same time.
